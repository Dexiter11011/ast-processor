# 03 — Таблицы и рисунки

## GFM-таблицы

Стандартный синтаксис GitHub Flavored Markdown:

```markdown
| Параметр | Значение | Единица |
|----------|----------|---------|
| Timeout  | 30       | сек     |
| Retries  | 3        | —       |
```

Выравнивание столбцов задаётся двоеточиями в строке-разделителе:

```markdown
| Левый | Центр | Правый |
|:------|:-----:|-------:|
| A     | B     | C      |
```

## Директива таблицы

Перед таблицей можно задать параметры оформления:

```markdown
<!-- table: borders=none -->

| Колонка 1 | Колонка 2 |
|-----------|-----------|
| Данные    | Данные    |
```

| Значение | Эффект |
|----------|--------|
| `borders=none` | Таблица без видимых границ (layout-таблица) |

## Маркеры ячеек

Специальные маркеры в начале содержимого ячейки управляют заливкой, выравниванием и объединением.

### Заливка фона

```markdown
| Продукт | Q1 | Q2 |
|---------|----|----|
| {bg:yellow}Виджет A | {bg:green}100 | {bg:blue}120 |
```

Цвет — имя (`yellow`, `green`, `blue`, `red`, `gray`) или hex без `#` (`E8F4FD`).

### Вертикальное выравнивание

```markdown
| Метка | Значение |
|:-----:|:--------:|
| {valign:center}:По центру: | {valign:center}:Ячейка: |
```

### GOST-выравнивание (двоеточия по краям)

Альтернативный способ задать выравнивание текста в ячейке:

```markdown
| :по центру: | :слева | справа: |
```

| Маркер | Выравнивание |
|--------|--------------|
| `:текст:` | по центру |
| `:текст` | по левому краю |
| `текст:` | по правому краю |

Маркеры `{bg:...}` и `{valign:...}` можно комбинировать:

```markdown
| {bg:blue}{valign:center}:Центрированная ячейка: |
```

### Объединение ячеек

**Горизонтальное** — пустые ячейки в строке:

```markdown
| Регион | Город | Население |
|--------|-------|-----------|
| Европа |       | —         |
| Беларусь | Минск | 9.4M    |
```

**Вертикальное** — маркер `^^` в первой колонке объединяемых строк:

```markdown
| Группа | Товар | Кол-во |
|--------|-------|--------|
| Фрукты | Яблоко | 5     |
| ^^     | Банан  | 3     |
| ^^     | Вишня  | 2     |
| Овощи  | Морковь | 8    |
```

## Изображения

```markdown
![Описание схемы](schema.png)
```

- Путь к файлу — **относительно каталога**, где лежит `.md`
- Поддерживаются PNG, JPEG, GIF, WebP
- Файл должен существовать на диске — иначе конвертация завершится ошибкой

### Обычное изображение vs рисунок с подписью

| Вариант | Markdown | Результат |
|---------|----------|-----------|
| Простое изображение | `![alt](path.png)` | Картинка без нумерации |
| Рисунок с подписью | `![alt](path.png)` + `<!-- caption: figure ... -->` | Нумерованный рисунок, попадает в LOF |

Пример рисунка с подписью (подробнее в [разделе 04](04-navigaciya-i-oglavlenie.md)):

```markdown
![Схема архитектуры](architecture.png)

<!-- caption: figure Обзор архитектуры -->
```

Директива caption должна стоять **сразу после** изображения.
