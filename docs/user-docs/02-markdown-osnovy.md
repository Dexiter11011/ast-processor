# 02 — Основы Markdown

md2docx поддерживает подмножество **CommonMark + GFM** (GitHub Flavored Markdown). Ниже — синтаксис, который можно использовать при написании технических документов.

## Заголовки

Заголовки перв–третьего уровня получают стили Word и автоматические закладки для оглавления и ссылок.

```markdown
# Заголовок 1
## Заголовок 2
### Заголовок 3
```

## Абзацы и форматирование

```markdown
Обычный абзац текста.

**Жирный текст** и *курсив*.

~~Зачёркнутый текст~~

`inline code` — моноширинный фрагмент в строке.
```

## Списки

### Маркированный список

```markdown
- пункт 1;
- пункт 2;
  - вложенный пункт;
  - ещё один.
```

### Нумерованный список

```markdown
1. первый;
2. второй;
3. третий.
```

### Task lists (чеклисты)

```markdown
- [ ] Не выполнено
- [x] Выполнено
```

Чекбоксы отображаются как символы Unicode (☐ / ☑), а не как интерактивные элементы Word.

## Blockquote и разделитель

```markdown
> Цитата или примечание.

---

Горизонтальная линия-разделитель.
```

## Блоки кода

````markdown
```python
def hello():
    print("Hello")
```
````

## Ссылки

### Внешние ссылки

```markdown
[Документация MXDR](https://example.com/docs)
<https://example.com/page>   ← autolink
```

### Внутренние ссылки на заголовки

```markdown
[См. раздел «Архитектура»](#arhitektura)
```

Закладка формируется из текста заголовка (slug). Для перекрёстных ссылок на рисунки и таблицы используйте директивы из [раздела 04](04-navigaciya-i-oglavlenie.md).

## YAML front matter

Metadata документа задаётся в блоке `---` в начале файла:

```markdown
---
title: Техническое задание
author: F6 Security
subject: MXDR — техническое задание
keywords: MXDR, ТТ, безопасность
---
```

| Поле | Куда попадает |
|------|---------------|
| `title` | Свойство документа `dc:title`, поле TITLE |
| `author` | Свойство `dc:creator`, поле AUTHOR |
| `subject` | Тема документа |
| `keywords` | Ключевые слова |

CLI-флаги `--title`, `--author`, `--date` дополняют или переопределяют значения для шаблонов.

## Таблица «синтаксис → результат»

| Синтаксис | Результат в DOCX |
|-----------|------------------|
| `#`–`###` | Заголовки со стилями Heading 1–3 |
| `**текст**` | Жирный |
| `*текст*` | Курсив |
| `~~текст~~` | Зачёркнутый |
| `` `код` `` | Inline code |
| ` ``` ` блок | Блок кода (стиль NoSpacing) |
| `- пункт` / `1. пункт` | Маркированный / нумерованный список |
| `- [ ]` / `- [x]` | Task list с символами ☐ / ☑ |
| `> цитата` | Blockquote |
| `---` | Горизонтальная линия |
| `[текст](url)` | Гиперссылка |
| `[текст](#slug)` | Внутренняя ссылка на заголовок |
| `![alt](path.png)` | Изображение |
| `\| col \| col \|` | GFM-таблица |
| `---` front matter | Metadata документа |

## Что не поддерживается

| Синтаксис | Причина |
|-----------|---------|
| Raw HTML (`<div>`, `<span>` и т.д.) | Отключён в парсере |
| Footnotes (`[^1]`) | Вне области поддержки |
| Math (`$...$`, `$$...$$`) | Вне области поддержки |
| Bare URL без `<>` (`https://...`) | linkify отключён — оборачивайте в `<>` или `[text](url)` |
| Definition lists | Нет правила парсера |
| Диаграммы (Mermaid и т.п.) | Вне области поддержки |
